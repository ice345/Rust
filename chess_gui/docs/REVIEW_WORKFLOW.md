# Review Workflow

本文档说明复盘交互语义，便于后续功能扩展时保持行为一致。

## 1. 基本概念

- 主线：原始对局走法。
- 分支：在任意节点选择不同走法后生成的变体线。
- 分析缓存：按 position key 存储的 `PositionAnalysis`。

## 2. 分析策略

- Stockfish：多深度复核（默认 `12/16/20`）。
- LC0 / Built-in：单轮策略（性能优先）。

## 3. 不重复分析规则

- 当局面 key 已命中缓存：
  - 直接使用缓存结果。
  - 不再次发起 UCI 分析请求。
- 回到主线或切回旧分支：
  - 若局面已分析过，必须秒级复用，不触发重新排队。

## 4. 分支行为

- 在分支线下，如果走法与“当前线下一手”一致：仅前进游标，不创建新分支。
- 在同一节点重复选择已存在分支走法：切换到已有分支，不重复创建。
- 可随时 `Return to Main Line`，并恢复主线语义。

## 5. UI 显示契约

- Top3 走法在棋盘绘制箭头，并与 Analysis 面板同步高亮。
- `MoveClassification` 在落点显示 icon，统计表显示分布。
- 底部导航 `|< < > >|` 与当前步数计数保持一致。

## 6. 回归建议

修改 Review 后至少执行：

```bash
cargo fmt
cargo test
cargo clippy --all-targets
```
